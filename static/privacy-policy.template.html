Privacy Policy

{{APP_NAME}} Links (the "Extension")

Data Collection

This extension does not collect, store, or transmit any personal data. It does not use cookies, analytics, or tracking of any kind.

How It Works

The extension runs a content script on Google Docs, Sheets, Slides, Drawings, and Drive pages only when they are loaded inside an iframe within the {{APP_NAME}} web application. Its sole function is to intercept clicks on Google Drive links and redirect navigation back to the parent {{APP_NAME}} app via the browser's postMessage API.

Permissions

  • Content script access on Google Workspace domains — required to detect and intercept Drive link clicks inside embedded document previews. No data is read or extracted from these pages.
  • Content script access on {{APP_HOST}} — sets a single DOM attribute (data-atlas-ext) so the web application can detect whether the extension is installed. No data is read, collected, or transmitted.

Third-Party Sharing

No data is shared with third parties. The extension communicates exclusively between the embedded iframe and its parent {{APP_NAME}} window.
